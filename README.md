# Java Day 62 - Reverse a Number

## Problem
Write a Java program to reverse a given number.

## Concepts Used
- Scanner
- int
- while loop
- Modulus operator (%)
- Division operator (/)
- Arithmetic operators

## Example

Input:
1234

Output:
Reverse: 4321

## Logic
1. Get the last digit using num % 10.
2. Add the digit to the reverse number.
3. Remove the last digit using num / 10.
4. Repeat until the number becomes 0.

## Learning
Learned how to reverse a number using a while loop,
modulus operator, and division operator in Java.
